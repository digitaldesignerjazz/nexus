## Notes

- The Yggdrasil Forum itself has **no clearnet address** — it lives only on the overlay. Access requires a running Yggdrasil node with at least one peer.
- Matrix and GitHub Discussions are the only community channels reachable without the mesh.
- IRC servers are open to peering; BonoboNET uses unrealircd.
