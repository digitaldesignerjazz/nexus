## Runbook (Suno Custom Mode)

1. Suno öffnen → **Custom** aktivieren.
2. Modell: **v4.5** für den ersten Take.
3. Style of Music exakt oben einfügen.
4. Lyrics exakt oben einfügen (Tags jeweils auf eigener Zeile).
5. Exclude einfügen.
6. Vocal: **Female**.
7. Generate → ersten Take prüfen.
8. Wenn Hook sitzt: denselben Prompt **unverändert** auf **v5** feuern (Final).
9. Eine Variable pro Regeneration — nie Style und Lyrics gleichzeitig ändern.
10. Ergebnis hier verlinken, sobald Sir den Cast freigibt.
