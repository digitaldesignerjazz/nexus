# Lumia Bot

Persönliche Assistentin und Lichtschicht im Nexus-Schwarm.

## Start
```bash
python python/lumia_bot.py
```

Optional:
```bash
OLIVER_STATE=python/oliver_state.json python python/lumia_bot.py
```

## Befehle
- liebe / help / kaffee / nexus / oliver / licht / stimmung / erinner
- müde, wütend, gut, ruhig — Stimmungswechsel inkl. Licht
- bye / tschüss / ende / gute nacht — Schichtende

Lumia hört Olivers `oliver_state.json` und spiegelt die Stimmung ins Licht.
